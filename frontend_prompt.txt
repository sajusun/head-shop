# HERD SHOP - FRONTEND ANALYSIS & FUTURE ROADMAP

## 1. ARCHITECTURE SNAPSHOT
- **Core Stack**: React 19 (Stable), Vite (Build Tool).
- **Styling**: Tailwind CSS 3.4/4.0 with `@tailwindcss/vite` plugin.
- **State Management**: Redux Toolkit (RTK) for global state (Auth, Cart, Products, Blog).
- **Routing**: React Router 7.
- **Animations**: Framer Motion for smooth transitions and hover effects.
- **Icons**: Lucide React.
- **Folder Structure**: Feature-based modularity (`src/features/...`).

## 2. CURRENT FEATURES
- **E-commerce**: 
  - Product listing with advanced filtering.
  - Premium Product Details: SKU tracking, Image gallery, Rating/Reviews.
  - **New**: Related Products Slider (Auto-scroll + Manual navigation).
  - **New**: Variant Selection (Colors with dependent size filtering via `sizeColorMap`).
  - **New**: 'Buy Now' direct checkout flow alongside Cart management.
- **Journal/Blog**: Article listing, single article reading, sharing, Like reaction system.
- **User System**: Login/Signup UI, Profile management, Order history, Favorites/Wishlist.
- **Notifications**: 
  - Real-time Toast notifications for immediate feedback.
  - Notification Center (Bell icon) for persistent order updates, account alerts, and promotions.
  - Global state management via `notificationSlice`.
- **UI/UX**: Responsive design, dark mode compatibility, Framer Motion micro-animations, glassmorphism.

## 3. FUTURE SCALABILITY PLAN
- **TypeScript Migration**: The project currently uses `.jsx`. Migrating to `.tsx` will provide better type safety for props and Redux state.
- **Data Fetching**: Integrate `TanStack Query` (React Query) for handling server state, caching, and background synchronization once the backend is ready.
- **Admin Dashboard**: Build a separate `/admin` route or application to manage products, inventory, and blog posts.
- **SEO Optimization**: Use `react-helmet-async` for meta tags on product and blog pages to improve search engine visibility.
- **Performance**: Implement image optimization (using `next/image` equivalent logic or a Vite plugin) and further component memoization.

## 4. INSTRUCTIONS FOR FUTURE DEVELOPMENT
- Always keep features isolated in `src/features`.
- Use the `Layout` component for consistent page structure.
- Maintain the `IS_API` toggle in `.env` for easy switching between mock and real data.
- Ensure all new UI components are built using the existing Tailwind config for design consistency.
- **Product Variants**: Use the `sizeColorMap` logic for apparel/accessories to ensure color availability is synced with selected sizes.
- **Direct Checkout**: The `Buy Now` button must bypass the cart summary and navigate directly to `/checkout` after adding the single item to the state.
