# HERD SHOP - BACKEND DEVELOPMENT GUIDE & MASTER PROMPT (LARAVEL)

## 1. PROJECT OVERVIEW
HERD SHOP is a premium eCommerce platform built with React 19, Vite, and Tailwind CSS. The backend will be built with Laravel to provide a robust, scalable, and secure API for the frontend.

## 2. BACKEND ARCHITECTURE (RECOMMENDED)
- **Runtime**: PHP 8.2+
- **Framework**: Laravel 11
- **Database**: MySQL (Relational for orders, inventory, and users)
- **Authentication**: Laravel Sanctum (Token-based API Auth)
- **API Pattern**: RESTful API with JSON Resources
- **File Storage**: Laravel Storage (with S3 or Cloudinary driver for images)
- **Payment**: Integration with SSLCommerz / Stripe / Chapa (via Laravel packages)

## 3. DATABASE SCHEMA (ENTITY RELATIONSHIPS)
- **Users**: id, name, email, password, role (admin/user), avatar, phone, timestamps, softDeletes.
- **Categories**: id, name, slug, image, type (product/blog), timestamps.
- **Products**: id, category_id, name, slug, sku, description, price, offer_price, stock, variants (JSON with colors, sizes, sizeColorMap), is_featured, timestamps, softDeletes.
- **Product_Images**: id, product_id, image_path, is_primary, timestamps.
- **Orders**: id, user_id, order_number, subtotal, tax, total_amount, status (pending/processing/shipped/delivered), payment_status, shipping_address, timestamps.
- **Order_Items**: id, order_id, product_id, quantity, price, selected_color, selected_size, other_variants (JSON), timestamps.
- **Blogs**: id, author_id, title, slug, excerpt, content, featured_image, status (draft/published), timestamps.
- **Comments**: id, blog_id, user_id, content, status (pending/approved), timestamps.
- **Reviews**: id, product_id, user_id, rating, comment, timestamps.

## 4. MASTER PROMPT FOR BACKEND GENERATION
> "Build a production-ready Laravel 11 API backend for an eCommerce site called HERD SHOP. The frontend is built with React 19 and Redux Toolkit.
> 
> **Requirements:**
> 1. **Auth System**: API-based Signup, Login, and Profile Management using Laravel Sanctum.
> 2. **Product API**: CRUD for products, categories, and inventory. Implement SKU management and dynamic product variations. **Crucial**: Support dependent variations using a mapping system (e.g., specific colors only available for specific sizes) as implemented in the frontend. Implement advanced filtering (category, price range) and search.
> 3. **Order System**: Checkout logic, support for 'Buy Now' (direct checkout), automated order number generation, user order history, and an Admin order management dashboard API.
> 4. **Blog/CMS API**: CRUD for blog posts, categories, and a comment system with approval logic.
> 5. **Admin Authorization**: Use Spatie MediaLibrary for images and Spatie Permissions or simple 'role' check for protecting Admin routes.
> 6. **API Structure**: Use API Resources for consistent JSON responses and Form Requests for validation.
> 7. **Best Practices**: Implement Service Classes for business logic, Repositories (optional), and clear separation of concerns.
> 8. **Middleware**: Ensure CORS is configured and use standard Auth/Guest middlewares.
> 
> 9. **Variation Logic**: The `variants` field in the Product API should provide:
>    - `colors`: Array of objects (name, code).
>    - `sizes`: Array of strings.
>    - `sizeColorMap`: Object mapping sizes to available color names (e.g., `{"S": ["Red", "Blue"], "M": ["Green"]}`).
>    - `switches/other`: Dynamic arrays for other attributes.
> 
> Provide a clean Laravel structure with Controllers, Models (with relationships), Migrations, and API routes."

## 5. INTEGRATION STEPS (FUTURE)
1. **API URL**: Set `VITE_API_URL` in the frontend `.env` to point to the Laravel dev server (e.g., `http://localhost:8000/api`).
2. **Axios Configuration**: Update `src/utils/axios.js` to include the `Authorization: Bearer <token>` header from Redux state.
3. **Redux Thunks**: Migrate mock data logic to asynchronous thunks that hit the Laravel endpoints.
4. **Environment Variables**: Configure Laravel `.env` for `DB_DATABASE`, `APP_URL`, and `SANCTUM_STATEFUL_DOMAINS`.

## 6. DEVELOPMENT ROADMAP
- **Phase 1**: Database Migrations & Sanctum Auth Setup.
- **Phase 2**: Product & Category API with Image Uploads.
- **Phase 3**: Cart Persistence & Checkout Logic (DB-driven) with 'Buy Now' support.
- **Phase 4**: Order Fulfillment & Payment Gateway Webhooks.
- **Phase 5**: Blog/Journal API & Interaction (Comments/Likes).
- **Phase 6**: Admin Statistics & Dashboard API.
