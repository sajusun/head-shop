# HERD SHOP - BACKEND DEVELOPMENT GUIDE & MASTER PROMPT

## 1. PROJECT OVERVIEW
HERD SHOP is a premium eCommerce platform built with React 19, Vite, and Tailwind CSS. The frontend is already structured with features like Product Listing, Cart, Checkout, Blog (Journal), and User Profiles.

## 2. BACKEND ARCHITECTURE (RECOMMENDED)
- **Runtime**: Node.js
- **Framework**: Express.js (or NestJS for better scaling)
- **Database**: MongoDB (Flexible for products/blog) or PostgreSQL (Relational for orders/inventory).
- **Authentication**: JWT (JSON Web Tokens) with HttpOnly Cookies.
- **File Storage**: Cloudinary or AWS S3 for product/blog images.
- **Payment**: SSLCommerz / Stripe / Chapa (as per region).

## 3. DATABASE SCHEMA (ENTITY RELATIONSHIPS)
- **Users**: id, name, email, password, role (admin/user), address, phone.
- **Products**: id, name, slug, description, price, offerPrice, category, stock, images[], ratings, reviewsCount.
- **Orders**: id, userId, items[{productId, quantity, price}], totalAmount, status (Pending/Shipped/Delivered), paymentStatus, shippingAddress.
- **Blogs**: id, title, slug, excerpt, content (HTML/JSON), featuredImage, author, tags, createdAt.
- **Comments**: id, blogId, userId, content, createdAt.

## 4. MASTER PROMPT FOR BACKEND GENERATION
> "Build a production-ready Node.js/Express backend for an eCommerce site called HERD SHOP. The frontend uses React 19 and Redux Toolkit.
> 
> **Requirements:**
> 1. **Auth System**: Signup, Login, Profile Management using JWT.
> 2. **Product API**: CRUD for products, filter by category/price, search functionality.
> 3. **Order System**: Checkout flow, order history for users, order management for admins.
> 4. **Blog System**: API for listing posts, single post details, and comments.
> 5. **Admin Protected Routes**: Only admins can add/edit products and blogs.
> 6. **Middleware**: Error handling, Auth guards, and CORS.
> 7. **Validation**: Use Joi or Zod for request validation.
> 8. **Database**: Use Mongoose (MongoDB) with clean models.
> 
> Provide a modular folder structure (controllers, models, routes, middlewares, config)."

## 5. INTEGRATION STEPS (FUTURE)
1. **API Service**: Update `src/services/api.js` in frontend to point to `process.env.VITE_API_URL`.
2. **Redux Thunks**: Convert existing mock-data logic in Redux slices to use Axios calls to the backend.
3. **Environment Variables**: Use `.env` for both frontend (API URL) and backend (DB URI, JWT Secret).
4. **CORS Configuration**: Ensure the backend allows requests from the frontend domain.

## 6. DEVELOPMENT ROADMAP
- **Phase 1**: User Auth & Profile API.
- **Phase 2**: Product & Category Management.
- **Phase 3**: Cart Persistence (Optional: Store cart in DB for logged-in users).
- **Phase 4**: Checkout & Payment Gateway Integration.
- **Phase 5**: Blog & Interaction (Comments/Likes) API.
- **Phase 6**: Admin Dashboard API.
